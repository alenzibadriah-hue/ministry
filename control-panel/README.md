# لوحة تحكم منصت — Ministry Control Panel

لوحة داخلية لفريق منصت: التسويق والحملات، العملاء والاستخدام، التقرير الأسبوعي، استيراد بيانات CSV، الوكيل الذكي، والفريق والصلاحيات.

> كل الأرقام في اللوحة **بيانات تجريبية** للعرض. شاشة «استيراد البيانات» فقط تحسب من ملف CSV حقيقي داخل المتصفح.

## الصفحات

| الصفحة | الملف |
|---|---|
| تسجيل الدخول | `index.html` |
| نظرة عامة | `dashboard.html` |
| التسويق والحملات | `campaigns.html` |
| العملاء والاستخدام | `clients.html` |
| التقرير الأسبوعي | `reports.html` |
| استيراد البيانات | `import.html` |
| الوكيل الذكي | `agent.html` |
| الفريق والصلاحيات | `team.html` |

## التشغيل

موقع ثابت بدون أي تثبيت: افتحي `index.html`، أو فعّلي GitHub Pages للمستودع وافتحي `/control-panel/`.

- `assets/dc.js` محرّك صغير يرسم كل صفحة ويشغّل الأزرار والفلاتر.
- `assets/fonts/` خطوط الهوية (Azer وBukra)، و`assets/munsit-logo.png` شعار منصت.

ملاحظة: تسجيل الدخول والصلاحيات تصميم فقط، وما فيه تحقق فعلي من الحسابات.
